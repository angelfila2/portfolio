# Technology logo sources

These existing brand icons are used beside technology names in portfolio badges.

- FastAPI, SQLite, Express and Prisma: Devicon, https://github.com/devicons/devicon (MIT).
- Ollama: official image at https://ollama.com/public/ollama.png.
- ChromaDB: the chroma-core GitHub organisation avatar, https://github.com/chroma-core.

Brand names and marks belong to their respective owners. The generic Security
APIs badge uses the existing Lucide icon library rather than a brand logo.
